# Yaldi brand direction

The maintainer accepted the **Yaldi** name and robot-detective direction on
2026-10-20. The product stays **Yald**, with the existing `Yald.` wordmark.

Yaldi is a compact, friendly robot with a coral detective cap, an ink face panel,
paper-colored body and magnifying glass. Use the simple mark at small sizes and
the full character for a finding, analysis/loading state, or empty state. Findings
must still identify their evidence and limitations in text.

These files are exploration references, not a production animation atlas. The
PNG was generated with the built-in imagegen tool and has an alpha channel. The
SVG is a separate editable concept. Preserve their originals when creating
production variants; do not relabel the four poses as evenly framed animation frames.

The first release needs a crisp static identity and useful state artwork. A
16 px favicon needs a simpler face/eyes treatment. Animation is follow-up work;
future motion should respond to state changes, respect reduced motion, and be hideable.
