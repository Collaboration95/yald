## opencodex community note (Discussion or issue)

I built Yald, a local desktop dashboard for existing opencodex and Claude Code
usage records. Meet Yaldi adds an optional Labs tab: Project Radar compares
projects, Cache Detective compares read discounts with write premiums, and Context
Replay shows recorded submitted-input sequences. Each finding opens the exact
request evidence behind it. Dollar amounts are API list-price equivalents, not
subscription bills or proof of savings; source coverage and unknown data stay
visible. Source files stay untouched, while normal Claude ingestion retains
usage metadata in Yald's own local archive with no automatic expiry. The isolated
installed demo uses synthetic data and illustrative prices. Code, limitations
and GitHub tarball installation: https://github.com/Collaboration95/yald.
Feedback on investigations and metric definitions is welcome.

## Launch post

Meet Yaldi, Yald's little usage detective. Explore local opencodex and Claude
Code records with Project Radar, Cache Detective and Context Replay, then inspect
the requests behind each finding. Labs is optional; there is no new collector or
mandatory model call. Try `yald demo --open` after installing the 0.2.0 GitHub
tarball with its verified checksum. The demo uses synthetic examples and
illustrative prices; dollar amounts are API list-price equivalents, not bills or
proof of savings. Normal usage reads existing source logs and retains Yald's own
Claude usage archive without automatic expiry. Installation, screenshots and
limits: https://github.com/Collaboration95/yald. npm registry and Homebrew
availability remain unverified.
